## 概念說明

### MonST3R 的設計哲學

MonST3R 把「動態場景的 3D 重建」分成兩個獨立的問題：

```
第一步：局部測量
  model(frame_i, frame_j) → 「這兩幀之間的相對幾何」

第二步：全局整合
  TTO → 「找一個全局一致的 3D 結構，同時滿足所有局部測量」
```

這兩個問題是解耦的。模型只負責**測量**，TTO 只負責**整合**。

---

### 為什麼這個架構能處理動態場景

關鍵在第二步的「同時滿足所有局部測量」。

考慮一個動態物體（比如走動的人）出現在 frame 3：

```
pair (0, 3): 人在位置 A
pair (1, 3): 人在位置 B  
pair (2, 3): 人在位置 C
pair (4, 3): 人在位置 D
```

四個 pair 對「frame 3 中這個人的 3D 位置」給出四個**不同的答案**。TTO 試圖找到一個能同時滿足所有 pair 的全局解，但不存在這樣的解——因為這個人在不同 pair 中看到的幾何本來就不一致。

TTO 的應對方式：**不一致的像素殘差大 → confidence 加權後貢獻小 → 被多數靜態 pair 的一致梯度「壓過去」**。

這是個隱式的「多數決」機制，不需要顯式知道哪裡有動態物體。

---

### 該方向的核心假設

現在把「局部測量」那一步換成 VGGT：

```
原本：DUSt3R(frame_i, frame_j) → 局部幾何
換成：VGGT(frame_i, frame_j)   → 局部幾何（更準確）
```

TTO 的部分完全不動。

假設是：**如果每個 pair 的局部幾何測量更準確，TTO 整合出來的全局解也更好。**

具體說，VGGT 作為局部測量者的優勢在於：
- 更大的模型（1B vs ~300M）
- 在更多樣化的資料上預訓練
- depth head 和 point head 在靜態局部幾何上的精度更高

---

### 與現有 VGGT-Dyn 的根本差異

| | 現有 VGGT-Dyn | Path A |
|---|---|---|
| VGGT 的角色 | 提供初始值，TTO 圍繞它做小 delta 優化 | 提供每個 pair 的局部幾何測量 |
| TTO 的信號來源 | anchor loss（拉回 VGGT 初始） + 相鄰 flow | 所有 pair 的全局幾何一致性 + flow |
| 動態場景的處理 | anchor 把動態區域的誤差鎖住 | pair 間的不一致性自然暴露動態區域 |
| 跨幀約束 | 只有相鄰 pair 的 flow | O(N²) 個 pair 的幾何約束 |

現有 VGGT-Dyn 的問題是 VGGT 的「全局一致性」**吸收**了動態物體的錯誤，讓後續 TTO 看不到它。Path A 把 VGGT 切成 2-frame 片段，動態物體在不同片段下的幾何**重新變得不一致**，TTO 就能再次利用這個信號。

### 代價

VGGT 看 2 幀時，喪失了看 S 幀的跨幀 attention。但這不一定是大問題，因為：

- 我們要的不是 VGGT 的「全局一致性」，而是它的「局部幾何精度」
- 局部精度（depth head、point head 在兩幀下的預測）主要來自預訓練規模，不完全依賴多幀 attention
- 最終精度的上限由 TTO 的全局整合決定，不由單個 pair 決定

所以這個方向的本質是：**用 VGGT 的預訓練品質提升 MonST3R TTO 的測量品質，讓 MonST3R 原有的全局整合機制在更好的輸入上運作。**
